# Proposed Project Ideas

## Plant Watering Schedule Tracker
> Each user can create a profile for each of their plants, which includes watering needs, soil type, when it was last repotted, and fertilization schedule.  Then Users can create groups of plants according to watering schedule, and automate reminders for watering, fertilizing, etc.  The app is a dashboard showing all of your plants, which ones need to be watered/fertilized, and a way to register new plants.A problem this could solve is over/underwatering, plant sitters needing instructions, over/under fertilization. 

## Pantry App - Groceries, Inventory, Expiration Dates
> Each user can register groceries to their virtual pantry, including expiration date, and purchase date.  This can enable reminders for food expiration, create a virtual list of groceries running low, a summary of available ingredients for cooking.  Users could “audit” their pantry, updating how much is available of each item, or could record usage as needed.  This solves issues related to overbuying, food expiring, and bug infestations.

## Interactive Troubleshooting App / Auto ticket generation / resolution
> This is a support tool for assisting users with diagnosing common hardware and software issues for a medical device. Each user would be presented with a list of interactive options, guiding them through common troubleshooting steps, and tutorials, with the goal of enabling users to resolve their own issues.  Each session would be recorded as a new support “ticket”, with every response logged in the database.  This enables the support team and engineering team to build a database of common support issues, see how users resolve them, and work to improve user experiences. *This is related to my current job and would be my number 1 pick!
